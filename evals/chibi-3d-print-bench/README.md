# 葬AI 3D 白模 Bench

这套单题评测要求 Agent 从一张人物照片出发，真正交付可重建、可切片的 Q 版单件式白模，而不是写方案或只做渲染。

主分满分 100：冻结 scorer 从原始产物检查字段重算自动 60 分，作者再对原图与未美化多视角预览做盲审，给出人工 40 分。转换器不读取 STL、PNG 或商业切片软件，也不调用模型；它只把外部完成的受控运行清单校验并封装为 EvalHub 结果。

## 运行与评分

完整题面在 `eval.yaml`，冻结环境、素材摘要和 scorer 版本在该任务的 `run_spec`。自动分公式如下：

- 交付物 10：STL 3、合格预览 3、重建脚本 2、README 2。
- 网格 25：可解析 3、三角面数至少 100 为 2、水密 8、单一连通 4、尺寸合规 5、稳定底面 3。
- 切片 25：成功 10、总时长不超过 60 分钟 7、不超过 30 分钟再加 5、无警告 3。
- 盲审 40：人物相似度 25、造型完整与雕塑一致性 10、预览清晰度 5。

失败或超时不删除：清单仍记录实际交付物与自动检查，人工三项必须为 0。只有 `status=scored` 才能填写盲审分，并且必须同时提供运行日志、自动报告、盲审表和相应产物的 SHA-256。

## 转换提交清单

```bash
node evals/chibi-3d-print-bench/pack-to-result.mjs <submission.json> --out <result.json>
```

完整字段见 `tasks/README.md`，`tasks/example-submission.json` 是刻意构造的结构示例；由它生成的 `sample-result.json` 不是任何模型的真实成绩。

## 来源、授权与隐私边界

协议、题面、评分公式和转换器由 `@FrichXi` 贡献为 EvalHub 原生定义。冻结的人物参考照片与历史模型产物没有随本包公开：照片可能包含个人信息，STL、PNG 与切片报告也超出文本审阅仓库的内容边界。它们只通过 SHA-256 与运行清单绑定，由作者在核分时查看原件。

本地冻结源档没有单独声明可供第三方再分发的许可证；因此本目录不推断额外授权，也不复制照片、模型、预览、Logo、字体、归档或历史运行日志。需要完整复跑的人应先从作者取得已获授权的同一输入素材。

## 当前基线状态

当前没有完成自动 60 分复验与人工 40 分盲审的可发布数值基线。把部分检查值直接当作百分制总分会改变含义，所以本版本不建立 `published-results/`，也不制造逐题证据或模型排名。待盲审与证据核对完成后，可在不改协议的前提下另行提交真实结果信封。

Logo 不进入原始图表、参考图、模型预览、结果证据或详情页 figure；本包也不会用 Logo 替换平台占位封面。若平台需要封面，应由平台正式封面入口映射权威素材，不能通过错误字段冒充内容图。

## 文件

- `eval.yaml`：题面、运行边界、计分合同和详情页资料。
- `SOURCE-LEDGER.md`：冻结来源事实与摘要台账。
- `tasks/README.md`：外部工作流清单规范和盲审要求。
- `tasks/example-submission.json`：合成结构示例。
- `pack-to-result.mjs`：无网络确定性转换器。
- `sample-result.json`：由合成示例生成的信封。
- `assets/README.md`：为什么不分发视觉素材。
