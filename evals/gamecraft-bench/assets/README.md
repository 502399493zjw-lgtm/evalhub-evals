## 平台封面（不在本目录内）

GameCraft-Bench 的机台封面由投稿用户于 2026-08-11 在投稿会话中提供，并明确指定用于本评测集。
它不是上游仓库、论文、Godot、GitHub、Kenney 或 OpenGameArt 的素材，也不作为上游作者发表物引用。
本台账只记录投稿来源与用途，不把该图描述为上游官方封面或上游作者背书。

| 项目 | 值 |
| --- | --- |
| 用户提供原件 | PNG，1024×572，RGB，无透明通道，1,086,744 字节 |
| 处理方式 | 仅做居中 16:9 微裁切、缩放与 WebP 有损压缩；未重新生图、未添加内容 |
| 平台成品 | 960×540 WebP，71,544 字节 |
| 部署位置 | EvalHub 平台仓库 `apps/platform/public/eval-covers/v20260810/gamecraft-bench.webp` |
| 页面用途 | 评测集列表卡片与详情页机台封面 |

成品刻意放在平台仓库的版本化静态资源目录，而不是本内容仓库；因此本 `assets/` 目录仍为空。

以下素材**刻意不放入**本目录：

- 上游仓库的 `media/benchmark_title.png`：它是 Agent 生成画面的拼图，
  可能内嵌第三方资产美术，来源侧未逐一说明这些美术的许可。
- Kenney 与 OpenGameArt 资产库：它们本来就不在上游仓库里（仓库只提供下载清单），
  且 OGA 清单中混有少量 GPL 与 CC-BY-SA 条目，并非全部宽松许可。
- 官方项目页的游戏录像与 Godot 导出物：该站点自身内容没有独立许可文件。

如果将来需要在本目录放静态展示资源，必须使用可审阅的静态文件，
并在此登记其来源、授权依据与用途。
