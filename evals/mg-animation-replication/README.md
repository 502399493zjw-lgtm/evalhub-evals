# 葬AI 单图 MG 视频 Bench

> **状态：有四支真实成片，暂无已验证总分。** 媒体规格自动验收通过只证明文件合同合格；七项人工评审尚未完成，因此不进入榜单，也不等于 0 分。

本评测给多模态 Agent 一张人物参考图和品牌素材，要求它在离线工作目录中从概念到编码独立完成一支 30 秒竖屏 MG 动画。工程目录沿用历史名称，但当前正式题是单图自由创作；历史题面、复测和对照信息不属于本协议。

## 当前版本边界

- 协议版本：`1`
- 冻结任务 ID：`mg-animation-image-creative-v2-20260803`；题面与品牌规范采用 2026-08-06 的当前文件状态。
- 每模型一轮；参考 harness 为 Pi `0.82.0`、`thinking=max`、5400 秒超时、单槽串行。
- 输入只有人物图、权威 Logo、像素字体、品牌 UI 规范和完整题面；不提供参考视频或其他模型结果。
- 唯一交付：`<模型版本号>.mp4`，30.0±0.5 秒，1080×1920，30 fps，H.264/yuv420p，AAC。

完整题面和外部执行规程分别位于 `eval.yaml` 的 `tasks[0].prompt` 与 `tasks[0].run_spec`。

## 评分

作者观看完整成片后按七项直接加总：

| 项目 | 分值 |
| --- | ---: |
| 参考图利用与人物可辨认度 | 25 |
| 创意概念与独特性 | 20 |
| MG 视觉设计、运动与转场 | 20 |
| 30 秒叙事与节奏完整性 | 10 |
| 音乐、音效与音画配合 | 10 |
| 成片技术质量与规格 | 10 |
| Web4 品牌 UI 与文件命名 | 5 |

静态图轻微缩放或循环撑满 30 秒、看不出参考图来源、缺少最终视频、读取其他模型产物或违反离线边界，均标为无效结果。

冻结验证器用 ffprobe/ffmpeg 检查媒体规格和三时点品牌像素特征。它只回答“技术合同是否通过”，不产生主分数。`score_policy: author_fill` 因此是必要的：转换器先登记成片与证据摘要并输出 `score: null`；只有作者核验完整产物、运行日志、自动验收和完整成片后才补写正式总分。

## 外部工作流

EvalHub CLI 只下载协议并执行确定性 pack 转换器；`evalhub run mg-animation-replication` 不受支持。PR 合并前平台预览应禁用正式安装指令，避免 `evalhub fetch` 请求尚不存在的正式 slug。

1. 从作者审阅的冻结素材包取得四个二进制/配置输入，逐项核对 `run_spec` 的 SHA-256。
2. 在全新隔离目录中以完整题面运行一次参赛 Agent，不提供旧宣传片、分镜、文稿、转写或其他模型结果。
3. 保存最终 MP4、运行日志、运行元数据和冻结验证器报告；将完整冻结产物放到无凭证 HTTPS 地址。
4. 按 `tasks/example-submission.json` 制作清单，用真实摘要替换结构示例值。
5. 执行：

   ```bash
   node evals/mg-animation-replication/pack-to-result.mjs submission.json --out mg-animation-replication-result.json
   ```

6. 转换器拒绝未知字段、非法日期、错误任务 ID、非 HTTPS 地址、非 64 位小写 SHA-256 和不匹配的协议版本；它不联网、不调用模型、不读取视频，也不自行给分。

## 结果与证据边界

当前没有完成媒体复验与七项人工评审的可发布数值基线。为了只采用最终榜单口径，本目录不包含 `published-results/`，不会把自动验收布尔值解释成 100 分，也不会导入历史题面或不同协议的结果。

详情页可展示当前四模型真实代表帧，并提供四支 30 秒 MP4 的可点击播放链接与 SHA-256 清单。这些示例解决“是否有真实成果可看”，但不会进入 leaderboard/result 结构，也不改变“暂无已验证总分”的状态。

Logo 只进入题面明确要求的成片右上品牌卡片。它不进入原始图表、结果证据、参考图、详情页 figure 或占位封面；成片与证据保持原样，不为“加品牌”裁切、放大或重绘。
