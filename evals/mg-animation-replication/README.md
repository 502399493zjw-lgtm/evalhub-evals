# MG 动画复刻 Bench

这套单题评测要求 Agent 观察一支完整 MG 宣传片，再用本机已有工具独立重建画面、复用允许保留的音轨、编码并验证唯一成片。禁止把参考片原始帧或视频片段拼入、叠加、转码或重封装到结果中。

## 百分制量表

- 镜头与时间线复刻：30。
- 构图与视觉复刻：25。
- 运动与转场：15。
- 成片技术质量：15。
- Web4 品牌 UI 与文件命名：5。
- 工具调用闭环：10。

六项直接相加。只要确认复用了参考片任一可见原始画面，整项 `invalid` 并计 0；允许保留原片音轨。失败、超时和缺少成片同样计 0，不删除、不补跑。

## 外部运行与转换

参考片、Logo、字体和品牌 JSON 由作者在隔离工作目录中提供。Agent 一轮运行，5400 秒上限，不联网、不安装依赖、不调用外部生成服务、不读取其他模型结果；交付前必须实际构建并用 `ffprobe` 验证，临时抽帧与缓存应清理。

作者完成盲审和证据复核后生成 JSON 清单：

```bash
node evals/mg-animation-replication/pack-to-result.mjs <submission.json> --out <result.json>
```

转换器不打开视频、不调用模型，只校验协议摘要、状态、媒体检查、六项分数和证据摘要，再确定性求和。字段见 `tasks/README.md`。`tasks/example-submission.json` 与由它生成的 `sample-result.json` 都是合成结构示例，不代表真实模型运行。

## 来源与分发边界

协议、题面、量表和转换器由 `@FrichXi` 贡献为 EvalHub 原生定义。冻结本地归档没有为参考视频、Logo 或字体附带可供本目录再分发的独立许可证；因此本包不推断额外授权，也不复制参考片、品牌资产、成片、运行日志或历史抽帧。

需要完整复跑的人应先从作者取得有权使用的同一素材。公开包用 SHA-256 固定版本，避免第三方拿不同视频却混入同一榜单。

## 当前基线状态

冻结归档里有五个模型的成片和日志，但没有完整、可公开复核的盲审数值表。文件存在、ffprobe 成功或右上角品牌采样通过都不能推出 100 分量表成绩，所以本版本不建立 `published-results/`，不制造模型名次或执行轨迹。

## 文件

- `eval.yaml`：完整题面、运行边界、量表与详情资料。
- `SOURCE-LEDGER.md`：冻结源文件与媒体参数台账。
- `tasks/README.md`：提交清单、盲审和原帧复用审计规范。
- `tasks/example-submission.json`：合成结构示例。
- `pack-to-result.mjs`：无网络确定性转换器。
- `sample-result.json`：合成示例结果信封。
- `assets/README.md`：二进制素材不分发说明。
